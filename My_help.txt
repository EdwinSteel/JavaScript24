Метод join() — это встроенный инструмент JavaScript для работы с массивами. Если говорить просто: он берет все элементы массива и «склеивает» их в одну строку.

Как это работает
По умолчанию элементы разделяются запятой, но вы можете указать любой свой разделитель (символ, слово или даже пустую строку).

Синтаксис: array.join(separator)

separator (необязательно) — строка, которая будет стоять между элементами. Если не указать, будет использована запятая.

Примеры использования
1. Базовый пример (без аргументов)
Если вы ничего не передадите в скобки, массив просто превратится в строку через запятую.

JavaScript

const fruits = ['Apple', 'Banana', 'Orange'];
const result = fruits.join(); 

console.log(result); // "Apple,Banana,Orange"
2. Свой разделитель
Можно использовать пробелы, тире или любые другие символы.

JavaScript

const fruits = ['Apple', 'Banana', 'Orange'];

console.log(fruits.join(' - ')); // "Apple - Banana - Orange"
console.log(fruits.join(' и '));  // "Apple и Banana и Orange"
3. Пустая строка (склеивание «вплотную»)
Часто используется, чтобы собрать слово из отдельных букв.

JavaScript

const letters = ['J', 'a', 'v', 'a'];
console.log(letters.join('')); // "Java"
Важные нюансы
Типы данных: Если в массиве есть числа, булевы значения или объекты, join() попытается преобразовать их в строку.

Пустые значения: Если элемент массива равен null или undefined, в итоговой строке он превратится в пустую строку "".

Исходный массив: Метод не изменяет оригинальный массив, а создает новую строку.
